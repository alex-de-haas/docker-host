# Hosty Brand Assets — PNG

Набор пересобран без SVG: только PNG-файлы и `favicon.ico`. Иконки сделаны из растрового исходника, чтобы не было проблем с пропорциями при SVG-рендеринге.

## Структура

```text
hosty-brand-assets-png/
├── icons/
│   ├── light/   # тёмная иконка для светлой темы
│   └── dark/    # светлая иконка для тёмной темы
├── logos/       # цветной знак и большие логотипы PNG
├── favicon/     # favicon PNG-варианты + favicon.ico
├── favicon.ico  # multi-size ICO в корне
├── brand-tokens.json
└── preview.png
```

## Размеры иконок

Для каждой темы подготовлены PNG: 16×16, 20×20, 24×24, 32×32, 48×48, 64×64, 96×96, 128×128, 256×256, 512×512 px.

## Логотипы

- `logos/hosty-logo-color-large-1024.png` — основной большой цветной логотип на белом фоне.
- `logos/hosty-logo-color-large-512.png` — уменьшенная версия.
- `logos/hosty-logo-color-large-native-1254x1254.png` — PNG в исходном размере растрового макета.
- `logos/hosty-logo-color-horizontal-on-white-900x300.png` — горизонтальная PNG-версия на белом фоне.
- `logos/hosty-logo-color-horizontal-transparent-900x300.png` — горизонтальная PNG-версия с прозрачным фоном.
- `logos/hosty-mark-color-transparent-512.png` — цветной знак с прозрачным фоном.

## Favicon

- `favicon.ico` содержит размеры: 16, 32, 48, 64, 128, 256 px.
- В папке `favicon/` также лежат отдельные PNG-варианты.
