# Completion and source retention

Commit only selected reviewed files with explicit authorship when authorized. Local acceptance
must verify a clean canonical target, expected heads and a fast-forward; never force/reset/stash
to bypass divergence. Complete requires Core's fresh completion evidence across all repositories.
Close, Complete and sandbox Finish are different actions. Unfinished source is retained.
Use locally is a separate reviewed ordinary-runtime action against accepted canonical source;
never promote test users, secrets or sandbox data. Connecting a remote is explicit and must
retain local identity. A local commit is not a remote backup.

Keep a preview running when the operator asks to inspect it. Finish is an explicit environment
operation, independent of Complete and chat deletion. Export requested results first. Reuse the
same Finish requestId after interruption and inspect the observed operation until resources are gone;
an accepted request or a missing browser page is not proof of cleanup. Verify child containers,
networks, caches, data, users and credentials are removed. Parent source and unfinished worktrees
must remain. Cleanup of a workspace requires Core's completion checks across every repository;
inactivity alone must never remove unfinished work.
